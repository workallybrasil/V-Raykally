## ✨ Features

- **Live render queue** with real-time state and progress
- **Drag-and-drop ordering** to control priority
- **Simple / Pro modes** for fast or detailed configuration
- **V-Ray Standalone integration** with path validation
- **Local-first** operation with no cloud dependency

---

## ✅ Quick Start

1. Install V-Raykally for your platform.
2. Open **Settings** and set your V-Ray Standalone executable path.
3. Add `.vrscene` / `.vrs` files and press **Play**.
